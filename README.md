🏥 Healthcare Analytics using Python

📌 Project Overview

This project demonstrates an end-to-end Healthcare Analytics workflow using Python. The objective is to analyze healthcare operational data, uncover business insights, and visualize key performance indicators that can support hospital management in data-driven decision-making.

The project covers data cleaning, preprocessing, exploratory data analysis (EDA), visualization, and business reporting

🎯 Objectives
Analyze hospital revenue trends
Understand appointment status patterns
Identify top-performing doctors
Analyze treatment-wise revenue
Study patient demographics
Evaluate payment methods
Analyze insurance provider usage
Generate business insights using Python

💡 Business Insights
Pediatrics generated the highest revenue among all specializations.
Chemotherapy contributed the highest treatment revenue.
Central Hospital produced the maximum revenue.
Credit Card was the most frequently used payment method.
Medicare Plus covered the largest number of patients.
Appointment completion rate indicates opportunities to reduce cancellations and no-shows.
Patient demographics reveal a balanced distribution across different age groups.
